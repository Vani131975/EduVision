# EduVision

EduVision : ML-Powered Student Performance Prediction For Enhanced Online Learning
EduVision is a smart, machine learning-based platform designed to assess student performance in online learning environments. By predicting academic outcomes and identifying at-risk students, EduVision helps educators take timely, personalized interventions to improve student success.

## Project Overview

EduVision uses machine learning models to analyze key academic indicators like attendance, participation, and assignment performance to classify students into performance risk levels. The system provides actionable insights and content-driven notifications for educators to support struggling students in a timely and personalized manner.

## Tech Stack

Python (Core language)

Flask (Backend framework)

XGBoost (Student performance classification)

Pandas, NumPy (Data preprocessing and analysis)

Scikit-learn (Model evaluation and utilities)

Matplotlib, Seaborn (Data visualization)

Render (Deployment platform)

Gemini AI (Personalized content generation for notifications)

## Features

Predict student performance and risk level using ML

Visualize performance trends and feature importance

Alert educators about high-risk students

Generate intelligent, AI-driven feedback messages

Provide data-driven suggestions for interventions

Secure backend with REST API endpoints for integration

## How EduVision Works

Preprocesses student data using Python libraries

Applies the XGBoost classifier to predict performance risk

Visualizes trends and risk levels using Seaborn and Matplotlib

Uses Gemini AI to generate personalized messages for students

Allows educators to view insights and intervene early

## Use Cases

Early intervention in online education platforms

Personalized student support at schools and colleges

Academic risk monitoring for remote or hybrid classes

Institutional reporting and decision-making support
